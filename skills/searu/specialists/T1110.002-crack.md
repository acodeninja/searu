# crack — recover plaintext from a hash or KeePass file (T1110.002, CWE-916)

Turn a captured hash into a usable password with John the Ripper and a wordlist — the MD5s a SQL dump
yields, or the master password of a downloaded KeePass/Office/zip file. Exploitation tier — the ROE
must allow-list T1110.002 and name an authoriser. Take hashes from `searu loot --reveal`.

Run (the target is only for scope; the cracking is offline):

    searu run crack --technique T1110.002 --target http://host:port -- \
      --hash <hash> --format raw-md5 --wordlist seclists:Passwords/Common-Credentials/Pwdb_top-10000.txt
    searu run crack --technique T1110.002 --target http://host:port -- \
      --file out:incident.kdbx --wordlist seclists:Passwords/Common-Credentials/Pwdb_top-10000.txt

`--format` is a John format (`raw-md5`, `raw-sha256`, `bcrypt`, …); omit it for a `--file`, which is
converted and auto-detected. Read results:

    searu loot --reveal            # the recovered plaintext (category password)
    searu findings --tool crack    # a confirmed CWE-916 finding

Then log in with the recovered credential, re-crawl the authenticated surface (`browser --login`) and
re-run `searu coverage`. Don't paste raw John output. See `searu tool advice crack`.
