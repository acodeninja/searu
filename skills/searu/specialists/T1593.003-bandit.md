# bandit — Python SAST (T1593.003, Analysis)

Scan Python source you obtained during the engagement for insecure APIs, injection sinks and unsafe
defaults. Passive tier — allow-listing T1593.003 in the ROE is enough; no authoriser needed. The
target is a workspace-relative path written `src:<dir>`, mounted read-only at `/src`.

Run — point it at the Python source inside the engagement workspace:

    searu run bandit --technique T1593.003 --target src:loot/acme-src

Add bandit's own flags after `--` (e.g. `-- --severity-level high` to cut noise). Read results:

    searu findings --tool bandit

Each finding is one bandit test hit, titled by the test id (Bxxx), evidence `file:line`, tagged with
the test's CWE; severity maps bandit LOW/MEDIUM/HIGH. All are static and need review — triage each
against the running app. A confirmed injection sink promotes to an exploitation run with an authoriser.
Do not paste raw bandit output. See `searu tool advice bandit` for detail.
