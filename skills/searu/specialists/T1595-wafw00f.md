# wafw00f — WAF/CDN detection (T1595)

Identify a web application firewall or CDN in front of one in-scope target. Active tier — allow-listing
T1595 in the ROE is enough; no authoriser needed.

Run:

    searu run wafw00f --technique T1595 --target http://host:port

Read the result:

    searu observations --kind waf

A `waf` observation names the firewall and vendor; nothing is recorded when no WAF is detected. If a
WAF is present, tune later tools — sqlmap tamper scripts, nuclei rate limits, slower fuzzing — and
expect blocked payloads. Do not paste raw wafw00f output. See `searu tool advice wafw00f` for detail.
