# trufflehog — secret scanning (T1593.003, Analysis)

Sweep a source tree you obtained during the engagement for hardcoded credentials, keys and tokens
using trufflehog's detector catalogue — a complement to gitleaks' regex sweep. Passive tier —
allow-listing T1593.003 in the ROE is enough; no authoriser needed. The target is a workspace-relative
path written `src:<dir>`, mounted read-only at `/src`.

Run — point it at the source directory inside the engagement workspace:

    searu run trufflehog --technique T1593.003 --target src:loot/acme-src

Verification is off by default so found secrets are never sent to third-party services. To verify (and
confirm which credentials are live) add `-- --results=verified,unknown,unverified` — only with
authorisation, since it transmits the secrets. Read results:

    searu findings --tool trufflehog

Each finding is one detection (CWE-798), titled by the detector, evidence `file:line`; the secret value
itself is not stored. A verified detection is Confirmed and a live credential. Do not paste raw
trufflehog output. See `searu tool advice trufflehog` for detail.
