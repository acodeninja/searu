# checkov — IaC misconfiguration scanning (T1593.003, Analysis)

Check the infrastructure-as-code in source you obtained during the engagement — Terraform,
CloudFormation, Kubernetes, Dockerfiles and more — for insecure defaults and policy violations. Passive
tier — allow-listing T1593.003 in the ROE is enough; no authoriser needed. The target is a
workspace-relative path written `src:<dir>`, mounted read-only at `/src`.

Run — point it at the source directory inside the engagement workspace:

    searu run checkov --technique T1593.003 --target src:loot/acme-src

Add checkov's own flags after `--` (e.g. `-- --framework terraform` to scope it). Read results:

    searu findings --tool checkov

Each finding is one failed check, titled by the check id (CKV…), evidence `file:line`; checkov does not
attach a CWE, so consult the check's guideline for the fix. A misconfiguration in reachable
infrastructure (open ingress, a public bucket) points at a concrete attack path to pursue within the
ROE. Do not paste raw checkov output. See `searu tool advice checkov` for detail.
