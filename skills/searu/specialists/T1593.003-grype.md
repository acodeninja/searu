# grype — software-composition analysis (T1593.003, Analysis)

Find known-vulnerable dependencies (by CVE/GHSA) in the lockfiles and installed packages of source you
obtained during the engagement. Passive tier — allow-listing T1593.003 in the ROE is enough; no
authoriser needed. The target is a workspace-relative path written `src:<dir>`, mounted read-only at
`/src`. The first run downloads grype's vulnerability database.

Run — point it at the source directory inside the engagement workspace:

    searu run grype --technique T1593.003 --target src:loot/acme-src

Add grype's own flags after `--` (e.g. `-- --only-fixed` to drop advisories without a fix). Read
results:

    searu findings --tool grype

Each finding is one vulnerable package, titled by the CVE/GHSA id, evidence the `package@version`;
severity is grype's. Confirm the flagged version is the one actually deployed, then a reachable,
exploitable CVE promotes to an exploitation run with an authoriser. Do not paste raw grype output. See
`searu tool advice grype` for detail.
