# brakeman — Ruby on Rails SAST (T1593.003, Analysis)

Scan a Rails application you obtained during the engagement for SQL injection, mass assignment, unsafe
redirects and other Rails-specific weaknesses. Passive tier — allow-listing T1593.003 in the ROE is
enough; no authoriser needed. The target is a workspace-relative path written `src:<dir>`, mounted
read-only at `/src`, and must be a Rails app root.

Run — point it at the Rails application inside the engagement workspace:

    searu run brakeman --technique T1593.003 --target src:loot/acme-rails

Add brakeman's own flags after `--` (e.g. `-- --confidence-level 2` to cut noise). Read results:

    searu findings --tool brakeman

Each finding is one warning, titled by the warning type, evidence `file:line`, tagged with the
warning's CWE; severity maps brakeman's confidence. All are static and need review — triage each
against the running app. A confirmed injection or auth flaw promotes to an exploitation run with an
authoriser. Do not paste raw brakeman output. See `searu tool advice brakeman` for detail.
