# gau — historical-URL mining (T1593, Reconnaissance)

Recover a domain's known URLs from public web archives (Wayback, CommonCrawl, OTX) without touching the
target — surfacing old endpoints, parameters and paths that may still be live. Passive tier —
allow-listing T1593 in the ROE is enough; no authoriser needed, no packets reach the target. The target
is a **bare domain**.

Run — point it at the domain in scope:

    searu run gau --technique T1593 --target acme.example

Widen it with gau's own flags after `--` (e.g. `-- --subs` to include subdomains). Read the surface:

    searu observations --kind endpoint

Each observation is an archived URL. Parameterised ones and old paths are prime targets: feed them into
discovery (arjun) and initial access (dalfox/sqlmap), and confirm which archived paths still resolve
against the live app. Do not paste raw gau output. See `searu tool advice gau` for detail.
