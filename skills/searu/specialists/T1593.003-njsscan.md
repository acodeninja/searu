# njsscan — Node.js / JavaScript SAST (T1593.003, Analysis)

Scan Node.js/JavaScript source you obtained during the engagement for command injection, unsafe
deserialisation, path traversal and other weaknesses. Passive tier — allow-listing T1593.003 in the
ROE is enough; no authoriser needed. The target is a workspace-relative path written `src:<dir>`,
mounted read-only at `/src`.

Run — point it at the JS/Node source inside the engagement workspace:

    searu run njsscan --technique T1593.003 --target src:loot/acme-src

Add njsscan's own flags after `--`. Read results:

    searu findings --tool njsscan

Each finding is one rule hit, titled by the njsscan rule id, evidence `file:line`, tagged with the
rule's CWE; severity maps njsscan ERROR/WARNING. All are static and need review — triage each against
the running app. A confirmed injection sink promotes to an exploitation run with an authoriser. Do not
paste raw njsscan output. See `searu tool advice njsscan` for detail.
