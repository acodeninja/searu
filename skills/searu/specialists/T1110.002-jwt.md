# jwt — crack a JWT signing key (T1110.002, CWE-347)

When a token is HMAC-signed (HS256), recover the shared secret from a wordlist: a guessable key lets you
sign arbitrary tokens. Exploitation tier — the ROE must allow-list T1110.002 and name an authoriser.
Take the token from `searu loot --reveal`. (An RS256 token has no shared secret to crack — forge it
instead, see the T1606.001 specialist.)

Run (the token and flags follow `--`; the wordlist is a `seclists:` reference):

    searu run jwt --technique T1110.002 --target http://host:port -- <JWT> -C \
      -d seclists:Passwords/Common-Credentials/Pwdb_top-10000.txt

Read results:

    searu loot --reveal            # the recovered key (category jwt-secret)
    searu findings --tool jwt      # a confirmed CWE-347 weak-signing-key finding

With the key, forge a token with tampered claims (set `role`/`user` to a privileged value) and replay it
against an authenticated endpoint. Don't paste raw jwt_tool output. See `searu tool advice jwt`.
