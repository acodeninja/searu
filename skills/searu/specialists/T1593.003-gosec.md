# gosec — Go SAST (T1593.003, Analysis)

Scan Go source you obtained during the engagement for injection sinks, weak crypto, unhandled errors
and unsafe defaults. Passive tier — allow-listing T1593.003 in the ROE is enough; no authoriser needed.
The target is a workspace-relative path written `src:<dir>`, mounted read-only at `/src`; gosec scans it
with Go's recursive package pattern.

Run — point it at the Go module inside the engagement workspace (it needs the tree's `go.mod`):

    searu run gosec --technique T1593.003 --target src:loot/acme-src

Add gosec's own flags after `--` (e.g. `-- -severity high` to cut noise). Read results:

    searu findings --tool gosec

Each finding is one gosec issue, titled by the rule id (Gxxx), evidence `file:line`, tagged with the
rule's CWE; severity maps gosec LOW/MEDIUM/HIGH. All are static and need review — triage each against
the running app. A confirmed injection sink promotes to an exploitation run with an authoriser. Do not
paste raw gosec output. See `searu tool advice gosec` for detail.
